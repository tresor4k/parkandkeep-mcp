Park & Keep MCP server

This host serves the Model Context Protocol endpoint of the Park & Keep airport parking index for AI assistants: /mcp (POST only, Streamable HTTP, read-only, no account). It has no other web pages.

Tools: airport_parking_options, airport_price_snapshot (airport aggregates only), airport_market_snapshot.

The data, its method and licence (CC BY 4.0): parkandkeep.com/en/data/airport-parking-index.
